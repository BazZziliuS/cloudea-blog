Прокси ставится перед Minecraft-серверами и прозрачно пробрасывает на них трафик. Один процесс обслуживает несколько серверов, каждый на своём порту.

## Что умеет

- Проксирует TCP и UDP.
- Проверяет доступность бэкендов и пишет в Telegram, когда сервер упал и когда вернулся.
- Считает входящий и исходящий трафик и число соединений, раз в час сохраняет в JSON и раз в месяц присылает отчёт.
- Передаёт бэкенду настоящий IP игрока через PROXY protocol v1.
- Ограничивает число одновременных соединений на сервер.
- Перечитывает конфиг по `SIGHUP` без остановки и корректно завершается по `SIGINT`/`SIGTERM`.

## Конфигурация

```json
{
  "servers": [
    {
      "name": "MyServer",
      "port": 25565,
      "target": "192.168.1.100:25565",
      "tcp": true,
      "udp": true,
      "max_connections": 200,
      "health_check": true,
      "proxy_protocol": true
    }
  ]
}
```

Сборка: `go build -o mcproxy ./cmd/mcproxy`, нужен Go 1.23 или новее.
